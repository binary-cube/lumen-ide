# Plan proiect — Editor de cod în Rust (nume de lucru: **Lumen**)

> „Lumen” e doar un nume de lucru, folosit ca prefix pentru crate-uri (`lumen-*`). Îl putem schimba oricând înainte de primul commit serios.

Un editor de cod rapid, desenat integral pe placa video, cu organizarea clasică de IDE, dar mai ușor și mai curat. Este construit pe module (plug-and-play) și organizat după Domain-Driven Design.

## Principii (pe scurt)

1. **Contract înainte de implementare.** Orice capabilitate (randare, limbaj, temă, terminal, sistem de fișiere) se definește întâi ca trait. Implementarea concretă e un adaptor care poate fi înlocuit.
2. **Domeniul nu știe de infrastructură.** Crate-urile de domeniu nu depind de `wgpu`, `winit`, `tree-sitter` sau de sistemul de fișiere.
3. **Totul e modul.** Limbajele, terminalul, arborele de proiect și temele se înregistrează în același registry și pot fi activate sau dezactivate din config.
4. **Performanța e o cerință, nu o optimizare de la final.** Fiecare fază are bugete măsurate (latență la tastare, FPS, timp de pornire).
5. **Temele sunt cetățeni de rangul întâi.** Nicio culoare hardcodată în UI: totul trece prin tokeni semantici.
